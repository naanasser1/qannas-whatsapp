    "market": "السعودية",

    "dialect": "لهجة خليجية خفيفة",
    "title": "قنص متاجر السعودية",
    "headline": "خمسة متاجر سعودية تبيع بالصور الثابتة",
    "sub": "سطر أو سطران يلخصان الدفعة.",
    "method": "كيف اُستخرجت العيوب — وصف الفحص الفعلي.",
    "limits": "ما لم يُتحقق منه: الإعلانات على تيك توك وميتا لم تُشاهد...",

## التشغيل

```bash
python scripts/build_workbook.py leads.json --out lead-gen-ksa-2026-08-26.xlsx
python scripts/build_board.py    leads.json --out board.html
```

`build_workbook.py` يحتاج `openpyxl` (مثبّت مسبقاً في بيئة Cowork). `build_board.py` بلا اعتماديات.

## أي حقل يظهر أين

| الحقل | ملف Excel | صفحة الويب |
|---|---|---|
| `title` | — | عنوان الصفحة في التبويب والمعرض |
| `headline` · `sub` | — | العنوان الرئيسي والسطر التعريفي |
| `date_ar` · `market` · `niche` · `dialect` | تبويب المنهجية | التاريخ في الترويسة (`date_ar` فقط) |
| `method` · `limits` · `next_step` | تبويب المنهجية | قسم «كيف اُستخرجت الملاحظات» |
| `projects_note` | تبويب المنهجية | تنبيه أعلى قسم المشاريع |

كل حقول `meta` اختيارية — السكربتان يستخدمان قيماً افتراضية لما ينقص فلا تتعطل الدفعة. لكن `limits` تحديداً لا تتركه للافتراضي: هو المكان الذي يعرف منه ناصر ما لم يُتحقق منه في هذه الدفعة بالذات.

ارتفاعات الصفوف تُحسب من طول النص، فالفقرات الطويلة في تبويب المنهجية تظهر كاملة بلا قص.

بعد التشغيل: أرسل ملف Excel بـ `SendUserFile`، وانشر `board.html` بأداة `Artifact` (الملف مكتفٍ ذاتياً بلا موارد خارجية عدا خطوط Google).
