# قناص على واتساب

جسر يربط أجينت **قناص** برقم واتساب بزنس: ترسل رسالة من جوالك، يشتغل الأجينت،
يرسل لك التقدّم أول بأول، ثم النتيجة النهائية وملف الإكسل وصفحة الويب — كل شي في المحادثة.

---

## كيف يشتغل

```
جوالك ──► واتساب ──► Meta Cloud API ──► ويبهوك السيرفر (Railway)
                                              │
                                              ├─ يتحقق من التوقيع والرقم
                                              ├─ يضع الطلب بالطابور ويرد 200 فوراً
                                              ├─ يشغّل قناص عبر Claude Agent SDK
                                              └─ يرجّع النص + الملفات على واتساب
```

الرد الفوري بـ 200 مقصود: Meta تنتظر ثوانٍ قليلة فقط، وقناص يحتاج دقائق. بدون الطابور
تعيد Meta إرسال نفس الرسالة وتنطلق الدفعة مرتين.

---

## ملفات المشروع

| الملف | وظيفته |
|---|---|
| `app/main.py` | الويبهوك، الأوامر، الطابور (عامل واحد لكل رقم) |
| `app/agent.py` | تشغيل قناص عبر Claude Agent SDK وجمع الملفات |
| `app/whatsapp.py` | إرسال نص، رفع ملف، إرسال مستند، تقسيم الرسائل الطويلة |
| `app/security.py` | التحقق من توقيع Meta وقائمة الأرقام المسموحة |
| `app/store.py` | SQLite: جلسة لكل رقم + منع تكرار الرسائل |
| `app/config.py` | كل الإعدادات من متغيرات البيئة |
| `agent_home/.claude/skills/qannas/` | نسخة المهارة التي يقرأها الأجينت |
| `test_local.py` | ٢٠ اختباراً بدون إنترنت وبدون مفاتيح |

## الإعداد — خطوة بخطوة

### ١. تطبيق Meta

1. افتح [developers.facebook.com/apps](https://developers.facebook.com/apps) ← **Create App** ← نوع **Business**.
2. أضف منتج **WhatsApp** ← **Set up**.
3. من صفحة **API Setup** انسخ:
   - **Phone number ID** → `WHATSAPP_PHONE_NUMBER_ID`
   - **رقم النسخة** الظاهر في مثال curl (مثل `v23.0`) → `GRAPH_API_VERSION`

### ٢. توكن دائم (مهم)

التوكن الظاهر في صفحة API Setup **ينتهي بعد ٢٤ ساعة**. للحصول على توكن دائم:

1. [business.facebook.com/settings](https://business.facebook.com/settings) ← **Users** ← **System Users** ← **Add**.
2. أعطه صلاحية **Admin**، ثم **Assign Assets** ← اختر تطبيقك وحساب واتساب.
3. **Generate New Token** ← اختر تطبيقك ← **Expiration: Never** ← فعّل:
   - `whatsapp_business_messaging`
   - `whatsapp_business_management`
4. انسخ التوكن → `WHATSAPP_ACCESS_TOKEN` (يظهر مرة واحدة فقط).

### ٣. App Secret

**Settings** ← **Basic** ← بجانب **App Secret** اضغط **Show** → `WHATSAPP_APP_SECRET`.

هذا ليس اختيارياً — بدونه يقدر أي شخص يعرف رابط الويبهوك أن يشغّل قناص على حسابك ويحرق رصيدك.

### ٤. مفتاح Anthropic

من [console.anthropic.com](https://console.anthropic.com) ← **API Keys** → `ANTHROPIC_API_KEY`.

### ٥. النشر على Railway

```bash
git init && git add -A && git commit -m "قناص على واتساب"
gh repo create qannas-whatsapp --private --source=. --push
```

ثم في [railway.app](https://railway.app):

1. **New Project** ← **Deploy from GitHub repo** ← اختر المستودع.
2. **Variables** ← الصق محتوى `.env.example` وعبّئ القيم.
3. **Settings** ← **Networking** ← **Generate Domain** — يعطيك رابط مثل
   `https://qannas-whatsapp-production.up.railway.app`
4. **Data** ← **Add Volume** ← Mount path: `/data` — كي تبقى الجلسات بعد كل نشر.

تحقق من الإقلاع بفتح `https://<رابطك>/health`. المطلوب `"ok": true` و`missing_settings` فارغة.

### ٦. ربط الويبهوك

في لوحة Meta ← **WhatsApp** ← **Configuration** ← **Edit** بجانب Webhook:

| الحقل | القيمة |
|---|---|
| Callback URL | `https://<رابطك>/webhook` |
| Verify token | نفس ما وضعته في `WHATSAPP_VERIFY_TOKEN` بالحرف |

اضغط **Verify and save**. ثم من **Webhook fields** اشترك في حقل **`messages`** ← **Subscribe**.

> فشل التحقق هنا سببه شبه دائم واحد من اثنين: التوكن غير متطابق، أو الرابط ما فيه `/webhook`.

### ٧. أضف رقمك

في وضع الاختبار، واتساب يرسل فقط لأرقام مسجّلة: **API Setup** ← **To** ← **Manage phone number list**
← أضف رقمك وأكّد الكود. (بعد توثيق البزنس يزول هذا القيد.)

ضع نفس الرقم بالصيغة الدولية بدون `+` في `ALLOWED_NUMBERS`، مثال: `966501234567`.

### ٨. جرّب

أرسل من جوالك إلى رقم البزنس:

```
مساعدة
```

إذا رد بقائمة الأوامر — الربط شغّال. بعدها جرّب `دفعة اليوم`.

---

## الأوامر

| الأمر | ما يسويه |
|---|---|
| `دفعة اليوم` | الدورة الكاملة: ٥ متاجر + مشاريع مفتوحة + إكسل + صفحة ويب |
| `حلل لي هذا المتجر: <رابط>` | فحص متجر واحد، الرد في المحادثة بلا ملفات |
| `اكتب رسالة لهذا المتجر: <رابط>` | فحص + رسالة تواصل جاهزة |
| `شوف المشاريع المفتوحة` | مستقل و Upwork فقط |
| `جديد` | يمسح سياق المحادثة ويبدأ من الصفر |
| `إلغاء` | يوقف المهمة الشغالة |
| `الحالة` | يخبرك إن كان فيه شي شغال وكم بالطابور |
| `مساعدة` | قائمة الأوامر |

أي نص آخر يُمرَّر لقناص كطلب عادي مع الاحتفاظ بسياق المحادثة السابقة.

## قيد مهم: نافذة الـ ٢٤ ساعة

واتساب يسمح للبزنس بإرسال رسائل حرة **فقط خلال ٢٤ ساعة من آخر رسالة أرسلتها أنت**.

- ✅ أنت ترسل «دفعة اليوم» → قناص يرد بحرية لمدة ٢٤ ساعة. هذا هو الاستخدام الطبيعي.
- ❌ قناص يبدأ المحادثة من نفسه (دفعة مجدولة الساعة ٨ صباحاً بدون أن ترسل شيئاً) → مرفوض
  إلا برسالة قالب (Template) معتمدة مسبقاً من Meta.

**الحل العملي للدفعة اليومية:** أنشئ قالباً بسيطاً في **WhatsApp Manager ← Message Templates**
باسم `qannas_daily` ونصه مثلاً «دفعة قناص جاهزة، رد بأي رسالة لأرسلها». تُرسل الرسالة القالب،
وردّك عليها يفتح النافذة، ثم يرسل قناص كل شي بحرية.

## التكلفة

| البند | تقريباً |
|---|---|
| Railway | من ٥$ شهرياً |
| Anthropic API | حسب الاستهلاك — الدفعة الكاملة عادةً بين ٠٫٥$ و٣$ |
| واتساب | محادثات الخدمة مجانية ضمن الحصة الشهرية؛ القوالب مدفوعة |

`AGENT_MAX_BUDGET_USD` سقف صلب للدفعة الواحدة — قناص يتوقف عنده ويخبرك، فلا تفاجأ بفاتورة.

## حل المشاكل

| العرض | السبب الغالب |
|---|---|
| فشل Verify and save | التوكن غير متطابق، أو الرابط بدون `/webhook` |
| السيرفر يستلم لكن ما يرد | الرقم غير موجود في `ALLOWED_NUMBERS` — راجع سجل Railway |
| `invalid signature` في السجل | `WHATSAPP_APP_SECRET` خاطئ أو من تطبيق آخر |
| توقف الرد بعد يوم | استخدمت التوكن المؤقت — ارجع للخطوة ٢ |
| الملفات ما وصلت | راجع السجل: حجم أكبر من ١٠٠MB، أو انتهاء صلاحية التوكن |
| `CLINotFoundError` | نادر — ثبّت `npm i -g @anthropic-ai/claude-code` وضع `cli_path` |
| نسيان السياق بعد كل نشر | ما ربطت Volume على `/data`، أو `DB_PATH` غير مضبوط |

السجلات في Railway ← **Deployments** ← **View Logs**، وهي بالعربي وتذكر سبب كل رفض.
